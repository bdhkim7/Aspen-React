VXVue: A Powerful Engine with an Intuitive User Interface

The VXVUE acquisition software is an award winning intelligent software solution that integrates the most advanced imaging processing. VXvue's image viewer program contains specialized modules to acquire, adjust, and manage diagnostic images created by the VIVIX-S Series.

VXVue: Award-winning software

VXVue's post-processing algorithm will further enhance image quality through features like fine details without visual artifacts, soft tissue delineation, Non-grid chest processing, grid line removal with clear resolution, and fine tuning

Furthermore, VXVue allows for easy customization through 3 types of image processing (soft, normal, hard predefined parameters), customizable themes & skins, and the freedom to choose layouts, logos and fonts
